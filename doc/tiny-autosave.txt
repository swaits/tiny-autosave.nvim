1. INTRODUCTION                                *tiny-autosave-introduction*

tiny-autosave.nvim automatically saves modified buffers when leaving insert
mode or when Neovim loses focus. Works out of the box with zero configuration.

==============================================================================
2. REQUIREMENTS                                *tiny-autosave-requirements*

- Neovim >= 0.12

==============================================================================
3. INSTALLATION                                *tiny-autosave-installation*

Add to your |vim.pack.add()| call: >lua

    "https://github.com/swaits/tiny-autosave.nvim",
<
That's it. The plugin auto-loads with defaults. To customize, call setup: >lua

    require("tiny-autosave").setup({
      events = { "InsertLeave", "FocusLost" },
    })
<
==============================================================================
4. CONFIGURATION                              *tiny-autosave-configuration*

                                                  *tiny-autosave.setup()*
setup({opts})

    Optional. The plugin works with defaults if you never call this.
    Calling setup reconfigures the plugin with the given options.

    All options shown with defaults: >lua

        require("tiny-autosave").setup({
          events = { "InsertLeave", "FocusLost" },
        })
<
    Parameters: ~
      {opts}  (table|nil) Configuration table

    Fields: ~
      {events}  (table) List of events that trigger auto-save.
                  Default: { "InsertLeave", "FocusLost" }
